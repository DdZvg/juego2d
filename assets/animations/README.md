# Datos de animaciones

Esta carpeta está reservada para los datos que describan animaciones
(orden de fotogramas, duración, bucle y eventos), separados de las
imágenes.

Las imágenes del jugador van en `assets/sprites/player/`. Aquí se podrá
guardar, por ejemplo, un archivo por personaje o arma cuando el sistema de
animación exista.

No crear todavía un formato definitivo: se definirá en la fase en la que
se implemente la animación, siguiendo el documento maestro.
