# Diseño del juego

La especificación vigente es el `ECOS_DEL_ABISMO_MASTERPLAN.md`, ubicado
en la raíz del repositorio. Ese documento es la fuente de verdad para
visión, pilares, mecánicas, arquitectura, fases y criterios de aceptación.

Este archivo no duplica el diseño para evitar dos versiones que puedan
contradecirse. Cuando se apruebe un cambio de diseño, se actualizará el
documento maestro o se creará aquí una decisión explícita que lo
complemente, indicando fecha y motivo.
